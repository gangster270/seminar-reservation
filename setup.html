모두가 같은 예약 현황 보기

예약 내용을 구글 스프레드시트에 모아두면, QR로 들어온 모든 사람이 같은 화면을 봅니다. 한 번만 설정하면 됩니다.

지금은 시험 모드입니다. 예약이 각자의 휴대폰에만 저장돼서, 다른 부서에는 보이지 않습니다.

1예약을 담아둘 스프레드시트 만들기

구글 계정으로 빈 스프레드시트를 하나 만듭니다. 이름은 회의실 예약 대장 정도면 충분합니다. 예약이 이 시트에 한 줄씩 쌓이고, 관리자는 여기서 바로 확인하거나 고칠 수 있습니다.

새 스프레드시트 만들기

2스프레드시트에 처리 코드 넣기

방금 만든 스프레드시트에서 확장 프로그램 → Apps Script 를 엽니다. 편집기에 있던 내용을 모두 지우고 아래 코드를 붙여넣은 뒤 저장합니다.

3웹 앱으로 배포하기

Apps Script 편집기 오른쪽 위 배포 → 새 배포 를 누르고, 톱니바퀴에서 웹 앱 을 고른 뒤 이렇게 설정합니다.

  • 실행 계정 — 나
  • 액세스 권한이 있는 사용자 — 모든 사용자

처음 한 번은 권한을 묻는 화면이 나옵니다. 고급 → (프로젝트 이름)(으)로 이동 을 눌러 계속 진행하세요. 내가 만든 스크립트라 안전합니다.

배포가 끝나면 /exec 로 끝나는 주소가 나옵니다. 그 주소를 복사하세요.

4주소 넣고 연결 확인하기

복사한 주소를 붙여넣고 확인을 누르면, 실제로 예약을 하나 넣었다가 다시 지워보며 제대로 연결됐는지 검사합니다. 검사용 예약은 자동으로 지워집니다.

5설정 파일에 넣기

assets/config.js 파일에서 backend 부분을 아래 내용으로 바꾸고 저장하면 끝입니다. GitHub 저장소에서 파일을 열고 연필 아이콘을 눌러 바로 고칠 수 있습니다.
