# 회의실 예약 시스템

부서 공용 회의실을 QR 하나로 예약하는 웹앱입니다. 설치할 프로그램도, 서버도, 로그인도 없습니다.
회의실 문 앞에 붙인 QR을 찍으면 바로 예약 화면이 열립니다.

- 월별 달력에서 날짜 선택 → 회의실별 시간표에서 **비어 있는 칸을 누르면 바로 예약**
- 누가(부서·이름·목적) 몇 시부터 몇 시까지 쓰는지 한눈에 표시
- 같은 회의실·같은 시간 **중복 예약 자동 차단**
- 예약할 때 정한 **비밀번호 4자리**로 본인이 직접 취소
- 월 단위 **CSV 내보내기** (엑셀로 열립니다)
- 휴대폰 기준으로 만들었고, PC·태블릿에서도 그대로 동작합니다

```
index.html            예약 화면
setup.html            공유 저장(구글 시트) 설정 안내 및 연결 확인
qr.html               인쇄용 QR 안내문 만들기
assets/config.js      ★ 회의실 이름·운영시간·저장방식 설정
assets/app.js         화면 동작
assets/store.js       저장소(브라우저 / 구글시트) 연결
assets/qrcode.js      QR 생성기 (외부 서비스 없이 자체 생성)
assets/style.css      디자인
apps-script/Code.gs   구글 스프레드시트 백엔드
```

---

## 1. 우리 회의실에 맞게 고치기

`assets/config.js` 파일만 고치면 됩니다.

```js
rooms: [
  { id: 'A', name: '제1회의실', capacity: 12, color: '#3182f6' },
  { id: 'B', name: '제2회의실', capacity: 6,  color: '#8b5cf6' },
],
openHour: 8,        // 오전 8시부터
closeHour: 20,      // 오후 8시까지
slotMinutes: 30,    // 30분 단위 예약
```

회의실이 3개로 늘어나면 `rooms` 에 한 줄만 추가하면 화면이 알아서 맞춰집니다.
`id` 는 한 번 정하면 바꾸지 마세요 (이미 저장된 예약이 이 값으로 회의실을 찾습니다).

## 2. 저장 방식 정하기 — **중요**

`config.js` 의 `backend.mode` 두 가지 중 하나로 동작합니다.

| 모드 | 저장 위치 | 특징 |
| --- | --- | --- |
| `local` (기본값) | 각자의 휴대폰·PC 브라우저 | **기기마다 내용이 다릅니다.** 화면을 미리 확인해 보는 용도 |
| `sheets` | 구글 스프레드시트 | **모든 부서가 같은 예약 현황을 봅니다.** 실제 운영용 |

여러 부서가 함께 쓰려면 반드시 **`sheets` 모드**로 바꿔야 합니다.
기본값인 `local` 상태에서는 A부서가 예약해도 B부서 휴대폰에는 보이지 않습니다.
(화면 오른쪽 위 배지에 `이 기기에만 저장 (시험 모드)` 라고 표시됩니다.)

### `sheets` 모드 설정 (10분, 구글 계정만 있으면 됩니다)

**`setup.html` 페이지가 순서대로 안내하고 연결까지 확인해 줍니다.** 배포된 사이트 주소 뒤에
`/setup.html` 을 붙여 열면 됩니다. (예약 화면 위쪽의 노란 알림을 눌러도 같은 곳으로 갑니다.)

1. **스프레드시트 만들기** — 구글 드라이브에서 빈 스프레드시트를 하나 만듭니다. (예: `회의실 예약 대장`)
2. **처리 코드 넣기** — 그 스프레드시트에서 **확장 프로그램 → Apps Script** 를 열고,
   있던 내용을 모두 지운 뒤 `apps-script/Code.gs` 내용을 붙여넣고 저장합니다.
   (`setup.html` 의 `코드 복사하기` 버튼을 쓰면 편합니다.)
3. **웹 앱으로 배포** — 오른쪽 위 **배포 → 새 배포 → 유형 선택(톱니바퀴) → 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - 처음 한 번은 권한 승인 화면이 뜹니다. `고급 → (프로젝트 이름)(으)로 이동` 으로 진행하세요.
4. **연결 확인** — 배포 후 나오는 `.../exec` 주소를 `setup.html` 에 붙여넣고 `연결 확인하기` 를 누릅니다.
   실제로 예약을 하나 저장했다가 되돌려 보며 5가지 항목을 검사하고, 어디가 잘못됐는지 짚어 줍니다.
5. **설정 파일에 넣기** — 확인이 끝나면 나오는 내용을 `assets/config.js` 의 `backend` 부분에 붙여넣습니다.

```js
backend: {
  mode: 'sheets',
  url: 'https://script.google.com/macros/s/............/exec',
},
```

저장하고 새로고침하면 노란 알림이 사라지고 오른쪽 위 배지가 **공유 서버 연결됨** 으로 바뀝니다.
이제 예약이 스프레드시트의 `reservations` 시트에 한 줄씩 쌓이고, 누가 어느 기기로 들어와도
같은 예약 현황을 봅니다.
관리자가 시트에서 직접 지우거나 수정해도 화면에 그대로 반영됩니다.

> 관리자 비밀번호: Apps Script 편집기의 **프로젝트 설정 → 스크립트 속성**에서
> `ADMIN_PIN` 에 숫자 4자리를 넣어두면, 그 번호로 누구의 예약이든 취소할 수 있습니다.
> (`local` 모드에서는 `config.js` 의 `adminPin` 값이 쓰입니다.)

비밀번호는 원문 그대로 저장되지 않고 해시(SHA-256)로만 시트에 남으며, 예약 목록을 조회할 때는
서버가 해시를 아예 내려보내지 않습니다.

## 3. 인터넷에 올리기 (GitHub Pages, 무료)

1. GitHub 저장소 → **Settings → Pages**
2. Source 를 **Deploy from a branch**, 브랜치는 `main`, 폴더는 `/ (root)` 로 지정하고 저장
3. 1~2분 뒤 아래 주소가 열립니다.

```
https://<GitHub-계정>.github.io/seminar-reservation/
```

사내망만 쓴다면 이 폴더를 그대로 사내 웹서버에 올려도 되고,
`sheets` 모드라면 파일 위치와 상관없이 같은 예약 현황을 봅니다.

---

## 4. QR 안내문 만들어 붙이기

배포된 주소 뒤에 `/qr.html` 을 붙여 접속합니다.

```
https://<GitHub-계정>.github.io/seminar-reservation/qr.html
```

주소·기관명·제목을 확인하고 **인쇄하기** 를 누르면 QR과 사용법이 함께 담긴 A4 안내문이 나옵니다.
회의실 문 앞과 각 부서 게시판에 붙여두면 됩니다.
QR은 외부 QR 생성 사이트를 거치지 않고 이 페이지 안에서 직접 만들어지므로,
주소가 외부로 새어 나가지 않고 인터넷이 없어도 다시 뽑을 수 있습니다.

---

## 5. 쓰는 방법 (직원 안내용)

1. QR을 찍으면 예약 화면이 열립니다.
2. 달력에서 날짜를 누르면 그 날의 회의실 시간표가 나옵니다.
3. **비어 있는 칸을 누르면** 그 시간으로 예약 창이 열립니다. (아래 `＋ 예약하기` 버튼도 같습니다.)
4. 부서명·예약자·시간과 **취소 비밀번호 4자리**를 입력하고 예약합니다.
5. 취소는 색칠된 예약 블록이나 목록의 `✕` 를 누르고 비밀번호를 넣으면 됩니다.

---

## 참고

- 예약 화면은 인터넷 주소(`https://`)로 열어야 정상 동작합니다. 파일을 더블클릭해서 여는 방식은
  브라우저 보안 정책 때문에 일부 기능이 제한될 수 있습니다.
- 지난 시간과 지난 날짜는 자동으로 잠깁니다. 예약 가능 기간은 `config.js` 의 `maxAdvanceDays`
  (기본 180일)로 조정합니다.
- 공유 서버가 잠깐 끊기면 마지막으로 받아둔 내용을 보여주고, 화면 아래에 안내 문구가 뜹니다.
